Pages turn a single QR code into a multi-Destination landing page. Instead of one QR code per system, create one code with multiple options.

## What is a Page?

When someone scans a QR code linked to a Page, they see a mobile-friendly page with multiple Destinations:

- "Start Inspection" → Opens Mitti (formerly SafetyCulture)
- "Log Maintenance" → Opens CMMS system
- "View Manual" → Opens documentation

## Page Mode vs Direct Mode

| Mode | Behavior | Best For |
|------|----------|----------|
| **Page Mode** | Opens landing page with multiple Destinations | Multi-system integration, audience routing |
| **Direct Mode** | Redirects immediately to single Destination | Simple redirects, single-purpose codes |

You can switch between modes at any time without reprinting.

## Key Benefits

**One Code, Every System**
Connect one QR code to multiple software systems. Users tap the Destination they need.

**Audience Routing**
Show different Destinations to different people:
- Staff see operational tools
- Customers see support info
- Technicians see maintenance access

**Professional Presentation**
Every scan is a branded experience. Customize colors, logos, and descriptions.

## Creating a Page

Pages are switched on per Tub, not per Link:

1. In the Tub's settings, turn on the page option (labelled "Show a profile page" in the
   current app). Every Item in that Tub then opens a page when scanned. Left off, scans
   pass straight through to a single Destination.
2. Create an Item in the Tub
3. Assign a Link to the Item
4. Add Destinations to route people to the systems they need

Assigning a Link only attaches the URL — on its own it does not produce a page. If a Tub is
set to pass through, its Items will keep redirecting no matter how many Links you assign.
An individual Item can override its Tub's setting.
