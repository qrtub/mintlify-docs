One toggle in **Settings → Scan behaviour** decides what scanning an Item does by default:
**Show a profile page**.

- **On** — a scan opens the Item's page, which can offer several Destinations. This is Page Mode.
- **Off** — a scan goes straight to a single Destination, with no page in between. This is Direct
  Mode, and it makes a **Default destination** setting appear further down the same tab.

## It is a default, not a rule

This sets the starting point for new Items. Any individual Item can be switched to the other mode
from its own settings, and that explicit choice always wins over the Collection.

The corollary matters: an Item that has *never* made an explicit choice follows the Collection.
Flipping this toggle changes how those Items resolve, including Items that already exist — most
often Items created by CSV import, which do not record a per-Item choice unless you give them
one.

## What changes in the interface

Turning the toggle on reveals the Collection's **Profile page** tab in settings, where you can
preview the page design and open the Page Editor. Turning it off hides that tab — and if you were
sitting on it, you land back on **Scan behaviour**. The page design itself is not deleted; it is
still there if you turn pages back on.

Turning pages off is also what surfaces the [Default Destination for New
Items](/collections/default-destination) builder, since a pass-through Item needs somewhere to
send the scan.

## Private pages

The same tab holds a second setting, under **Who can see these pages**: **Private pages**. When it
is on, scanning an Item in this Collection asks the visitor to sign in first, and only members of
your team get through. It applies whether the scan would open a page or go straight to a
Destination.

Unlike the scan toggle, it is not only a starting point for new Items: every Item follows it,
existing ones included, unless the Item overrides it with the **Private Page** box on its
**Destination** tab. New Collections start public. See [Page Privacy](/pages/page-privacy).

Private pages are part of the Scale plan. On other plans the switch carries a **Scale** badge and
opens an upgrade prompt instead of turning on; switching it off is always allowed.

## Choosing between them

Direct Mode is right when a scan has exactly one sensible outcome — a product page, an asset
record in one system, a form. It is the fastest path for the person scanning: no page, no tap.

Page Mode is right when one physical code has to serve more than one purpose or more than one
audience — an inspection app for the operator, a manual for the technician, a support form for a
customer. One code, several Destinations, no second Tag.

For a full comparison of the two modes, see [Direct Mode vs. Page
Mode](/pages/direct-mode-vs-page-mode).
