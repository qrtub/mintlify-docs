A Random Link is one whose slug QRtub picks: six lowercase letters, resolving at
`qrtub.com/{slug}`. You cannot choose the slug, and there is nothing to configure — which is
exactly why it is the default and the fastest way to get printable codes.

## How the slug is generated

Six letters from `a` to `z`, like `qrtub.com/bepjov`. No digits, no capitals, no punctuation.
That is 26⁶ — a little over 308 million addresses.

The length and the alphabet are fixed. There is no setting for a longer slug, a shorter one, or a
different character set anywhere in QRtub — if you send a request asking for one, it is ignored
and the standard six-letter slug is minted instead.

**Two slugs can never clash.** QRtub does not draw at random and check whether the result is
free; it derives each name from a counter through a cipher, and a cipher is a one-to-one mapping.
Two Links cannot arrive at the same name, so creating five hundred at once never asks you to
resolve a conflict and never fails partway through.

**A random slug can never collide with a numbered pattern either.** Numbered slugs always contain
digits, and random ones never do, so the two can share one address space without any reservation
scheme keeping them apart.

## Creating them

On the Links page, open the create form and choose **Random** as the strategy. Set **Number of
Links** — the form accepts up to 100 in one request — and create. Each Link comes into existence
unattached: a real, resolvable address with no Item, no Page and no destination until you give it
one.

Random is also the type QRtub uses when a Collection is set to mint a Link automatically for each
new Item. That is a Collection-level setting rather than a property of the Link itself.

## Case does not matter

`qrtub.com/bepjov` and `QRTUB.COM/BEPJOV` resolve to the same Link, as do numbered and custom
slugs. How a code is printed is a typography decision, not a correctness one — set it in capitals
on a plate if that reads better at distance.

QRtub writes the address in lowercase everywhere it displays one, so that is the form you will see
in the app and in an export.

## Older codes still work

Two things changed in September 2026, and neither breaks a code already in the field.

- **Random slugs used to be five characters** of letters and digits. Those addresses still
  resolve. Only newly minted ones are six letters.
- **Random Links used to sit under a `/r/` prefix** — `qrtub.com/r/x5fgd`. That address
  permanently redirects to the slug at the root, query string intact, so a tag produced before
  the change scans exactly as it always did. The prefix is gone from the interface and from
  anything QRtub generates now.

You do not need to replace anything. If you are printing a readable address under a code, print
what the app shows you today.
